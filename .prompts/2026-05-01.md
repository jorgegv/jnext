## Task 1: parallax.nex investigation — RESOLVED 2026-05-01

**parallax.nex now visually matches CSpect end-to-end** (user-validated GUI).
Three deep VHDL-faithfulness coordinate-space bugs were unmasking each
other; fixing all three (plus a fourth algorithmic regression caught by
the reviewer) brings rendering to parity. Landed on main as 7-commit
series ending at `31d4424`.

Fixes (each VHDL-grounded, each unmasked the next):

1. `cde0a45` — fix(video): per-scanline change-log tag = `vc - DISP_Y`
   (32), not raw VC. Renderer iterates fb_row 0..255; tags must be in
   the same space.
2. `f5bed99` — fix(copper): cvc origin = `min_vactive` (64), not
   `DISP_Y` (32). The previous off-by-32 was masked because the
   change-log was also off by 32 — Copper-driven NR writes happened to
   land at the right framebuffer row by accident. Fix #1 surfaced this.
3. `8fcb345` — fix(layer2): clip x/y on **destination** column/row
   (pre-scroll), per VHDL `layer2.vhd:167`. jnext was clipping
   `src_x`/`src_y` (post-scroll), making the 8-pixel side gutters
   wander with scroll. Always wrong, but only visible after fixes
   #1+#2 enabled L2 X-scrolling for the bottom strip.
4. `460fac6` — fix(video): per-line snapshots indexed by fb_row +
   pre-display vblank tag coalesced to 0. Two-part fix:
   (a) the SNAPSHOT mechanism (fallback colour, ULA-enable, border
   colour, tilemap scroll) had the same +32 raw-VC-vs-fb_row mismatch.
   (b) the original sentinel-0xFFFF tag for vblank writes stalled the
   per-scanline cursor walk (`while line == log[c]`) — leading-vblank
   entries blocked all visible-row replay. Coalescing pre-display
   vblank tags to 0 lets the cursor walk normally and applies vblank
   writes from fb_row 0 onwards (matching VHDL "writes effective
   immediately"). Reviewer-flagged.
5. `68408d1` — test(regression): magic-bp-func / magic-port-func
   load NEX from canonical `test/00regression/nex/` (script bug fix).
6. `51b04b5` — test(compositor): PSCAN-VBLANK-COALESCE-01 row —
   Copper WAIT vpos=258 (raw vc=10, vblank) MOVE NR 0x68=0x80
   propagates to fb_row 0 fallback. Regression-guard.
7. `31d4424` — test(refs): rebaseline copper-demo / tilemap-demo /
   dapr-tilemap_00 references (user-authorised, visually verified).
