## Task 63: investigate github issue 9

- Investigate github issue 9 and report to me before fixing
- **Root cause:** beast.nex is a 60 Hz demo (NR 0x05 bit 2). Since v0.98.0 (Task 56,
  commit `c7050fd4`) jnext honors 60 Hz → emulated 58 Hz, but the Qt/SDL frontend
  frame timer stayed hardcoded to 50 Hz. Core ran ~58 fps while the window presented
  ~50 → dropped frames, fast/juddery motion; `--silent` ran the demo at 50 fps.
  Confirmed via probe (60 Hz → 481536 mc/frame → 58.15 fps) + git bisect. Per-frame
  rendering is correct; capable hosts already hit 60 fps, weak hosts (danboid) stutter.
- **Fix:** `Emulator::frame_period_ms()`; both frontends pace from it (17 ms at 60 Hz,
  20 ms at 50 Hz), re-checked each tick. + discriminative unit (FP-01..03) + functional
  (frame-pacing-func) tests. Independently reviewed APPROVE (mutation-verified).
