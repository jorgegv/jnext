## Task 26: P3 + P5 SPI/NR03 conformance batch

- From the 2026-07 boot-branch review; non-boot-blocking VHDL conformance
  ("works by luck" gaps with our SD image):
  - SPI Ncr: exactly 2 idle bytes ($FF) before every R1 response (ours
    sends 1; fixed-count firmware readers can mis-latch).
  - CMD58 reply must not contain $FF payload bytes (tbblue.fw's reader
    skips $FF as idle and misaligns).
  - Real CRC-16/CCITT on data blocks (ours sends dummy $00s).
  - P3: cold-boot NR $03 machine-type default should be VHDL "011" (+3),
    not Pentagon-family (masked today by NextZXOS's explicit commit).
- Each item with a discriminative unit test.

- keep the existing option to load a specific SDcard image file, BUT
