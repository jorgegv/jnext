{#- Override of Material's partials/source.html (GH #nit, 2026-07-23). Material's stock source block carries data-md-component="source", which its bundle.js reads to fetch api.github.com/.../releases/latest and show the latest release top-right. That value is cached in localStorage and went visibly stale. We drop that attribute so Material's cached fetch never runs, and show TWO facts instead: * "This version " — the release the committed guide was rendered FROM. Static, from config.extra.doc_release in mkdocs.yml, so it is baked at render time and is always correct offline (the guide ships inside the packages). Deterministic: docs-check re-renders and byte-diffs, so nothing here may depend on wall-clock or network. * "Latest version " — the CURRENT GitHub release, fetched live with cache: 'no-store' so it is never stale. Fails silently offline / when rate-limited, leaving the em dash. The two stack one per line. Material lays its facts out as a flex ROW with an ellipsis, which put both on one line and truncated the first to "docs v0.99…" — unreadable, and the two were easy to mistake for one another.
