# 9. Reference

The option list in 9.1 is not a copy. It is generated from the same source as
the `jnext(1)` man page and `USAGE.md`, and a stale copy of it fails the
project's own test runs, so the three cannot disagree.

Everything else in this chapter points at the authoritative source rather than
repeating it. That is deliberate: a hand-kept restatement drifts out of date
the first time the thing it describes changes, and a manual that quietly lies
is worse than one that sends you somewhere else.
